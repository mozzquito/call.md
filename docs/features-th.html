Call.md ฉบับภาษาไทย

แอปประชุม AI Copilot ตัวเดิม บวกชุดฟีเจอร์ที่เติมเข้าไปให้ใช้งานกับภาษาไทยได้จริง — ตั้งแต่แปลสดระหว่างประชุม ไปจนถึงสรุปท้ายประชุมเป็นไทย และค้นหาข้ามการประชุมทุกครั้งที่เคยบันทึกไว้

จุดเริ่มต้น

ปัญหา 3 ข้อที่ทำให้ต้อง fork

Call.md ตัวต้นฉบับทำเรื่องประชุมได้ดีอยู่แล้ว แต่ยังมีช่องว่างสำหรับคนที่ประชุมเป็นภาษาไทยเป็นหลัก

01 ไม่รองรับภาษาไทย

ถอดเสียงสด (real-time streaming) ของเอนจินเดิมไม่รองรับภาษาไทย ทั้งที่การประชุมส่วนใหญ่คุยกันเป็นไทย

02 อยากได้ความเห็นที่สอง

อยากให้ AI agent ตัวอื่น (zcode, agy) ช่วยอ่านการประชุมแล้วสรุป/แปล ให้เป็นอีกมุมมองหนึ่งนอกเหนือจากสรุปหลักของแอป

03 ใช้กับไฟล์เก่าไม่ได้

อยากดึงไฟล์บันทึก Google Meet ที่มีอยู่แล้วย้อนหลังมาถอดเสียงและสรุปในแอปเดียวกัน ไม่ใช่แค่การประชุมที่บันทึกสดเท่านั้น

สิ่งที่เพิ่มเข้ามา

6 ฟีเจอร์ใหม่

แต่ละอันมีป้ายบอกว่าไปแก้ปัญหาข้อไหนจากด้านบน

แปล

แปลไทยแบบสด แก้ข้อ 01

เปิดใช้งานได้จาก Settings → Transcription — เมื่อเปิดแล้ว ทุกประโยคที่ถอดเสียงจบระหว่างประชุมจะถูกส่งไปแปลเป็นไทยและแสดงเป็นบรรทัดที่สองใต้ต้นฉบับทันที ไม่ต้องรอจนจบประชุม

คิวแปลทำงานคู่ขนาน (concurrency 2) พร้อมบริบทประโยคก่อนหน้า เพื่อให้คำแปลสอดคล้องกับสิ่งที่คุยกันมา

นำเข้า

นำเข้าไฟล์เก่า + ถอดเสียงแบบ batch แก้ข้อ 03

เลือกไฟล์วิดีโอ/เสียงที่มีอยู่แล้ว (เช่นไฟล์บันทึก Google Meet เก่า) ให้แอปอัปโหลดขึ้น VideoDB แล้วถอดเสียงแบบ batch ซึ่งรองรับภาษาไทยเต็มรูปแบบ ต่างจากโหมดถอดเสียงสด

ตัดข้อความเป็นช่วงตามจำนวนตัวอักษร ไม่ใช่ตามช่องว่างระหว่างคำ — เพราะภาษาไทยเขียนติดกันไม่มีเว้นวรรค

2nd

สรุปความเห็นที่สองจาก zcode + agy แก้ข้อ 02

กดปุ่มเดียว ให้ AI agent อีกสองตัว (zcode บน GLM, agy บน Gemini/Sonnet) อ่านบทถอดเสียงทั้งหมดแล้วเขียนสรุปของตัวเองแยกจากสรุปหลักของแอป เทียบมุมมองกันได้ในหน้าเดียว

รันแบบ process แยก มี timeout 3 นาที และถ้า output เกิน 1MB จะ kill process ทิ้งทันทีกันหน่วยความจำบวม

TH

แปลสรุปท้ายประชุมเป็นไทย แก้ข้อ 01

ไม่ใช่แค่คำพูดสดที่แปล — สรุปภาพรวม (Overview), ประเด็นสำคัญ (Key Points) และเช็คลิสต์หลังประชุม (Action Items) ก็ถูกแปลเป็นไทยเก็บไว้ถาวรด้วย แสดงคู่กับต้นฉบับภาษาอังกฤษ

ถ้าแปลไม่สำเร็จ จะไม่แสดงข้อความอังกฤษปนมาเป็นไทยหลอกๆ — ปล่อยว่างไว้ดีกว่าให้ข้อมูลผิด

ค้น

ค้นหาข้ามทุกการประชุม

ช่องค้นหาเดียวค้นได้ทั้งชื่อประชุม สรุป บทถอดเสียงเต็ม ทั้งภาษาไทยและอังกฤษปนกัน โดยใช้ SQLite FTS5 กับ tokenize='trigram' ซึ่งตัดคำเป็นชุดตัวอักษร 3 ตัว แทนการตัดตามช่องว่างแบบเดิม

เพราะ trigram ต้องการอย่างน้อย 3 ตัวอักษรถึงจะแมตช์ได้ คำสั้นกว่านั้นในคำค้นจะถูกตัดทิ้งก่อน ไม่งั้นจะทำให้ทั้งคำค้นไม่ขึ้นผลลัพธ์เลย

กัน

ป้องกันการนำเข้าไฟล์ซ้ำ + ล้างข้อมูลเมื่อล้มเหลว

เช็ค SHA-256 ของไฟล์ก่อนอัปโหลดทุกครั้ง ถ้าเคยนำเข้าไฟล์เดียวกันมาแล้วจะถามก่อนว่าจะนำเข้าซ้ำไหม และถ้ากระบวนการนำเข้าล้มเหลวหลังอัปโหลดสำเร็จ ไฟล์ที่ค้างอยู่บน VideoDB จะถูกลบทิ้งอัตโนมัติ ไม่ปล่อยขยะค้าง

พร้อมปุ่มคัดลอกเช็คลิสต์หลังประชุมเป็น markdown checklist ไว้วางต่อที่อื่นได้เลย

ยังอยู่ครบ ไม่ได้แตะต้อง — เพื่อให้เห็นภาพรวมทั้งแอป ไม่ใช่แค่ส่วนที่เพิ่มเข้าไป

ถอดเสียงแยกช่อง — เสียงเรากับอีกฝ่ายแยกกันชัดเจน
Live Assist — AI แนะนำสิ่งที่ควรพูด/ถาม แบบเรียลไทม์
Conversation Metrics — สัดส่วนการพูด, WPM, จับ monologue
MCP Auto-Trigger — เรียกเครื่องมือ MCP ตามบริบทการคุยโดยอัตโนมัติ
Bookmark — มาร์กช่วงสำคัญไว้ดูย้อนหลัง
Meeting Setup Wizard — AI ช่วยตั้งคำถามและวาระก่อนประชุม
Export + Webhook — ส่งออก markdown หรือส่งต่อ n8n/Zapier/CRM อัตโนมัติ
Google Calendar Sync — ดึงตารางประชุมที่จะถึงเข้ามาในแอป
Local-First Storage — ประวัติและบทถอดเสียงเก็บใน SQLite เครื่องตัวเอง
